# АИТЕХ · главная по концепции A «Сигнал»

Рабочий адаптивный сайт. Основа — концепция A «Сигнал» (`../a-signal/`), которую выбрал заказчик: двенадцать блоков, шрифты, сетка, тексты и движение перенесены из неё. Задание — `../brief/aixtex_claude_brief_v3.md`. В режиме согласования на странице есть панель с пятью палитрами, по умолчанию оранжевая палитра A.

Стек: Astro 5 (статическая сборка), TypeScript, обычный CSS, GSAP с ScrollTrigger. Живого WebGL на странице нет. Сцена Three.js и компоненты раундов 3–4 лежат в `_archive/round4/` и не собираются.

## Запуск

Нужен Node.js 22.18 или новее.

```bash
cd site
npm install
npm run dev        # http://localhost:4321
npm run build      # проверка типов (astro check) и сборка в dist/
npm run preview    # просмотр собранной версии
```

## Режимы

Режим задаётся переменными окружения в `.env` (образец — `.env.example`):

| Переменная | Значение | Что делает |
|---|---|---|
| `PUBLIC_REVIEW_MODE` | `true` (по умолчанию) | Режим согласования: панель палитр, `noindex, nofollow`, robots.txt закрывает сайт, неподтверждённые факты видны с пометкой. |
| | `false` | Публичная версия: панели нет, палитра фиксирована, есть canonical, robots.txt открыт, sitemap.xml заполнен, неподтверждённые факты скрыты. |
| `PUBLIC_APPROVED_PALETTE` | `signal`, `olive-signal`, `olive`, `bronze`, `gold` | Палитра публичной версии. На страницу попадает только она. |
| `PUBLIC_SITE_URL` | например `https://aixtex.ru` | Адрес сайта для canonical, og:image и sitemap. |
| `BASE_PATH` | `/` или подпапка | Нужна, если сайт лежит не в корне домена (GitHub Pages). |

```bash
PUBLIC_REVIEW_MODE=false PUBLIC_APPROVED_PALETTE=signal PUBLIC_SITE_URL=https://aixtex.ru npm run build
```

## Публикация на GitHub Pages

Версия для согласования лежит в папке `v3/` в корне репозитория и открывается по адресу https://sgoryanskya.github.io/aixtex_concept/v3/. Pages публикует ветку `main` из корня, поэтому в `v3/` хранится готовая сборка, а не исходники. После правок сборку нужно обновить и отправить в `main`:

```bash
cd site
PUBLIC_REVIEW_MODE=true BASE_PATH=/aixtex_concept/v3/ PUBLIC_SITE_URL=https://sgoryanskya.github.io npm run build -- --outDir dist-pages
rm -rf ../v3 && cp -R dist-pages ../v3
```

Сборку нельзя направлять сразу в `../v3`: при папке вне `site/` Astro кладёт рядом свои служебные файлы.

## Режим согласования

- **Панель палитр.** Кнопка «Палитра» стоит там, где в A был переключатель концепций: справа внизу, на телефоне справа вверху. Выбор сохраняется в адресе и в браузере.
- **Порядок выбора палитры при открытии:** `?palette=` в адресе → последний выбор (`localStorage`, ключ `aixtex.palette.v2`) → «Чёрный / оранжевый». Ключ сменён, чтобы бронза, сохранённая в прошлых раундах, не перебила новую палитру по умолчанию.
- **Параметр `?studio=0`** скрывает панель, `?studio=1` показывает.
- **Параметр `?hero=value`** показывает запасной вариант заголовка («Сложное / Ценное»). По умолчанию стоит выбранный 4 ноября «Сложное / Управляемое». Постоянный вариант задаётся в `HERO_VARIANT` в `src/data/content.ts`.

```text
/?palette=bronze&studio=1   бронза, панель на месте
/?hero=value                запасной вариант заголовка
```

## Где что менять

| Что | Файл |
|---|---|
| Тексты всех блоков, меню, варианты заголовка | `src/data/content.ts` |
| Семь решений каталога и их подробности | `src/data/solutions.ts` |
| Контакты, реквизиты, паспорт продукта и статус проверки | `src/data/company.ts` |
| Цвета пяти палитр | `src/data/palettes.ts` |
| Стили (перенесены из `a-signal/style.css`) | `src/styles/global.css` |
| Движение (перенесено из `a-signal/main.js`) | `src/lib/signal.ts` |
| Меню, заглушка, FAQ, форма (из `shared/base.js`) | `src/lib/ax.ts` |
| Блоки страницы, по одному файлу | `src/components/` |

Цвета в стилях не прописаны напрямую: палитра задаёт базовые цвета (`--ink`, `--t1`, `--signal`, `--fog`, `--d1` и другие, имена как в A), прозрачные оттенки и линии считаются из них через `color-mix`.

У каждого факта в `company.ts` есть статус: `confirmed` (подтверждено заказчиком), `site` (взято с aixtex.ru, показывается), `unverified` (в публичной версии скрыто). Что ждёт подтверждения, перечислено в `CONTENT_STATUS.md`.

## Поведение

- Форма не отправляет данные сама: кнопка «Подготовить письмо» открывает письмо в почтовой программе посетителя с заполненными полями. Бэкенда и сохранения заявок нет.
- Клавиатура: ссылка «К основному содержанию», роли в блоке «Кто это» (стрелки, Home, End), панели решений на `<dialog>` (Escape, фокус возвращается), меню, FAQ, панель палитр.
- `prefers-reduced-motion`: длинные прокрутки первого экрана, диалогов и анатомии превращаются в обычные блоки, импульсы и появления выключены.
- Без JavaScript текст виден целиком, подробности решений раскрыты прямо в странице.
